# 街霸6 随机按键玩具（虚拟手柄版）

让脚本替你在《街头霸王6》里「随机乱按」——适合在单机 / 训练模式里图一乐。

> ⚠️ **仅限单机 / 训练模式娱乐**。在线模式（排位 / 休闲 / 格斗大厅）使用任何自动化输入都违反卡普空服务条款，有封号风险，请勿使用。

## 为什么用虚拟手柄而不是模拟键盘

脚本通过 [ViGEmBus](https://github.com/nefarius/ViGEmBus) 创建一台**虚拟 Xbox 手柄**（内核级虚拟设备），系统与游戏都把它当作真实手柄：

- 走的是**设备级输入**，不是往窗口里注入键盘事件
- **不受键盘"同时按键数"限制**（多数键盘只有 6 键无冲），1~7 个键同时按都能如实送达
- 游戏按 XInput 读取，和真实手柄完全同一条路径

## 快速开始

**第一步（一次性）：装驱动**

下载并安装 ViGEmBus（微软签名驱动，一路"下一步"，装完建议重启一次电脑）：

- 官方发布页：<https://github.com/nefarius/ViGEmBus/releases>
- 本项目在 1.22.0 上验证通过（该版本是最终版，**不含会外联的更新器组件**）

**第二步（一次性）：装 Python 库**

```bat
py -m pip install vgamepad
```

需要带 tkinter 的完整 Python 3.8+（python.org 安装包默认就带）。

**第三步：用起来**

1. 双击 **`手柄乱按-按F9开始.cmd`** → 弹出一个小窗口，显示「● 已停止 —— 按 F9 开始」
   （此时虚拟手柄**已经就绪**，但**不会自己开始**，你尽管慢慢进游戏）
2. 打开街霸6 → 进训练模式
3. **按 F9 才开始乱按**（在游戏里直接按就行，不用切出来）；想停按 **F10**；想嘲讽按 **F8**
4. 玩完点小窗口的 `×` 关闭（虚拟手柄会一起卸载）

> 它**只在街霸6 是前台窗口时才发送**：切出去自动暂停、切回来自动继续。

**另一种用法（要调参数）**：双击 **`启动-手柄版.cmd`** → 完整面板，有「▶ 开始乱按 / ■ 停止 / 嘲讽」按钮 + 两个参数框，同样支持 F8/F9/F10。**参数会自动记住**（存在 `params.json`，迷你入口也跟着用同一套）。

## 随机规则

| 项目 | 行为 |
|---|---|
| 一组输入 | 方向随机 **1–2 个**（上/下/左/右）+ 拳脚随机 **1–5 个**（A/B/X/Y/RB/RT） |
| 拳脚个数 | **加权递减**：1 个 40% / 2 个 25% / 3 个 18% / 4 个 11% / 5 个 6% |
| 六个拳脚同按 | **永不进随机池**（在街霸6 里 = 嘲讽），只由 F8 手动触发 |
| 节奏 | 帧驱动：每组保持 **1–3 帧**（街霸固定 60fps，1 帧 ≈ 16.7ms），到点整组换下一组 |
| 空拍 | **15%** 概率什么都不按 |
| 特殊键 | 不发送 LB / LT（避开"蓝防 / 迸放"这类特殊动作键） |

实测约 **每秒 29 次换输入**、平均每组 **2.1 帧**。

## 热键

| 键 | 作用 |
|---|---|
| **F9** | 开始乱按 |
| **F10** | 停止 |
| **F8** | 嘲讽（六个拳脚键同时按 0.15 秒）—— 乱按没在跑时也能用 |

F8/F9/F10 是**轮询式全局热键**（不装驱动、不挂钩子、不需要管理员）；长按不会连发，按一下才触发一次。

## 文件

| 文件 | 说明 |
|---|---|
| `sf6_gamepad.pyw` | 主程序（tkinter 面板 + 前台窗口检测 + 随机引擎） |
| `手柄乱按-按F9开始.cmd` | **日常入口**：双击开迷你窗口（待命），进游戏后按 F9 开始 |
| `启动-手柄版.cmd` | 完整面板（可调参数 + 按钮） |
| `tools/verify_xinput.py` | 验证器：直接调 XInput API，证明虚拟手柄对游戏可见且按键可上报（不用开游戏） |

命令行参数：

```bat
py sf6_gamepad.pyw            :: 完整面板
py sf6_gamepad.pyw --mini     :: 迷你窗口
py sf6_gamepad.pyw --topmost  :: 面板置顶
py sf6_gamepad.pyw --auto     :: 启动即开始
py sf6_gamepad.pyw --selftest :: 只自检，不建窗口
```

## 排障

1. 弹窗出现 **`VIGEM_ERROR_BUS_NOT_FOUND`**（驱动装了但虚拟手柄总线没起来）→ 按顺序来：
   **重启一次电脑 → 重装 ViGEmBus → 再重启一次**
   （成因：驱动被卸载到一半，服务卡在「待删除 / 已禁用」状态）
2. 弹窗「缺少 vgamepad 库」→ `py -m pip install vgamepad`；
   装过还报同样的错 = 启动时用了别的 Python 解释器
3. 入口 `.cmd` 提示 `No Python with BOTH tkinter and the vgamepad package was found` → 手动启动：
   `pyw sf6_gamepad.pyw --mini --topmost`
4. 面板正常但游戏里角色不动：
   - **先开面板、再开游戏**（虚拟手柄是在面板启动时创建的，游戏要在枚举输入设备时看得见它）
   - Steam → 设置 → 控制器：**关掉 Steam 的 Xbox 手柄支持**（Steam Input 会让虚拟手柄输入不一致）
   - 确认游戏窗口是当前活动窗口
   - 游戏内 Options → Controls：确认 P1 用到了手柄
   - `Win+R` → `joy.cpl` 确认「虚拟 Xbox 手柄」存在
   - 家里有真实手柄可能抢占 P1 → 先拔掉真实手柄测试
5. 自检：`py sf6_gamepad.pyw --selftest`（会明确区分「库没装」和「驱动没起来」）
